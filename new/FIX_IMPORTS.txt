❌ ERREUR RENCONTRÉE
═════════════════════════════════════════════════════════════════════════════════

ModuleNotFoundError: No module named 'models'

File "app_streamlit.py", line 31
    from src.suite import TSPOptimizer, AllocationOptimizer, StorageOptimizer

File "src/suite.py", line 16
    from models import Agent, Order, Product, Warehouse, Location


🔍 CAUSE
═════════════════════════════════════════════════════════════════════════════════

Dans src/suite.py, l'import était :
    from models import ...      ❌ INCORRECT

Cela signifiait :
  • Chercher un module 'models' à la racine du projet
  • Mais 'models.py' est en réalité dans le dossier 'src/'

C'est un problème d'import absolu vs relatif en Python.


✅ SOLUTION APPLIQUÉE
═════════════════════════════════════════════════════════════════════════════════

L'import a été changé en :
    from .models import ...     ✅ CORRECT

Le point (.) signifie "from the current package" (depuis le package courant).

Changement précis dans src/suite.py ligne 16 :

  AVANT :
  ┌──────────────────────────────────────────────────────┐
  │ from models import Agent, Order, Product, ...       │
  └──────────────────────────────────────────────────────┘

  APRÈS :
  ┌──────────────────────────────────────────────────────┐
  │ from .models import Agent, Order, Product, ...      │
  └──────────────────────────────────────────────────────┘

  └─ Cherche 'models' dans le même dossier (package courant)
