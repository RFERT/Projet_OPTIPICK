📊 DONNÉES & MÉTRIQUES
═════════════════════════════════════════════════════════════════════════════════

ENTREPÔT
   Dimensions : 10 colonnes × 8 rangées
   Zones : A(Électronique), B(Livres), C(Alimentaire), D(Chimie), E(Textile)
   Allées : Lignes 2 et 5 (déplacement libre)
   Entrée : Position (0, 0)

AGENTS (7 total)
   ┌─────────────────────────────────────────────────────────────┐
   │ 3 Robots     : 20kg / 30dm³ | Vitesse 2.0 m/s              │
   │ 2 Humains    : 35kg / 50dm³ | Vitesse 1.5 m/s              │
   │ 2 Chariots   : 50kg / 80dm³ | Vitesse 1.2 m/s (+ humain)   │
   └─────────────────────────────────────────────────────────────┘

COMMANDES
   Volume : 20-30 commandes par jour
   Structure : ID, items[], deadline, priorité
   Produits : ~100 produits différents

DISTANCE
   Métrique : Manhattan |x₁-x₂| + |y₁-y₂|
   Unité : Mètres


🛠️ INSTALLATION DÉTAILLÉE
═════════════════════════════════════════════════════════════════════════════════

PRÉREQUIS
──────────────────────────────────────────────────────────────────────────────
✓ Python 3.8 ou supérieur
✓ Pip (gestionnaire de packages)
✓ Fichiers JSON présents : data/*.json

ÉTAPE 1 : Vérifier Python
──────────────────────────────────────────────────────────────────────────────
> python --version
Python 3.10.5 (ou plus récent)

ÉTAPE 2 : Installer Streamlit
──────────────────────────────────────────────────────────────────────────────
> pip install -r requirements_streamlit.txt
ou
> pip install streamlit matplotlib numpy pandas

ÉTAPE 3 : Vérifier l'installation
──────────────────────────────────────────────────────────────────────────────
> streamlit --version
Streamlit, version 1.28.0 (ou plus récent)

ÉTAPE 4 : Lancer l'application
──────────────────────────────────────────────────────────────────────────────
> streamlit run app_streamlit.py
